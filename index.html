05 Method

How this is modelled

  • Spawn order. Each spawn group rolls 10x first, then Triple, else a single frog. Group size is locked in before any size roll, so Big and Massive frogs never multi-spawn.
  • Size and gold. Every frog independently rolls Big; a Big frog then rolls Massive. Golden is rolled separately and can land on any size.
  • Multipliers. Loot multiplier applies to all frogs, Big and Massive stack on top for their sizes, and Golden multiplies whatever is left.
  • Quantities. A uniform base roll is multiplied, floored, and never drops below 1.
  • Caps. Frogspawn is capped at 3 / 3 / 6 and Lootbug Lantern at 3 / 6 / 9 for Basic / Big / Massive, regardless of multipliers — golden does not raise the cap.
  • Chances above 100%. Treated as guaranteed for these binary rolls.
  • Frogurt. Rarity is listed as "1/?" in game, so it is modelled as 1 in 196 by default and is adjustable in the advanced options.
